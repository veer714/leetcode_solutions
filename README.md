## 🏆 Pattern Cheat Sheet

| If you see... | Try... |
|:--|:--|
| Sorted array / "minimum X such that..." | 🔍 Binary search (on index *or* on the answer) |
| Contiguous subarray / substring | 🪟 Sliding window or ➕ prefix sum |
| "Next greater / smaller element" | 📚 Monotonic stack |
| Max/min in a moving window | 🚀 Monotonic deque |
| Grid with connected regions | 🧱 DFS / BFS / Union-Find |
| Dependencies / ordering | 🕸️ Topological sort |
| Overlapping subproblems | 🧠 Dynamic programming |
| Pairs, palindromes, in-place ops | 👉 Two pointers |
